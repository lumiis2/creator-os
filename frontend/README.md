# CreatorOS Auth Test Frontend

Minimal Vite + React app to test Supabase Auth against the CreatorOS backend.

## Environment
Copy `.env.example` to `.env` and fill:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_API_URL`

## Run

```bash
npm install
npm run dev
```

The app runs on `http://localhost:3000`.
